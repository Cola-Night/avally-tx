# [TX] Avally-TaxOne

## Commands

#### Docker Containers
```bash
# [Docker-Containers] Build & Start
docker-compose up -d

# [Python-Container] Terminal Open
docker exec -it tx-python bash
```

#### Exit terminal and remove Docker-Containers
```bash
# [Python-Container] Terminal Exit 
exit

# [Docker-Containers] Stop & Remove
docker-compose down
```
